# Tanki Online News

WordPress-тема новостного блога как в [tankionline.com/ru/news](https://tankionline.com/ru/news/).

## Требования

- WordPress 6.x
- PHP 8.1+

## Установка

1. Установить [Local](https://localwp.com/) и создать сайт tanki-online-news.

```bash
ln -s "/Users/danilpopravkin/Desktop/Учеба/WEB/Tanki/wp_theme_tanki_online" \
  "$HOME/Local Sites/tanki-online-news/app/public/wp-content/themes/tanki-online-news"
```
